# Sistema Help Desk - Backend

## Descripción

Backend del Sistema Help Desk. Este permite administrar tickets de incidentes mediante una API REST desarrollada con Node.js, Express y MongoDB.

## Tecnologías utilizadas

- Express.js
- Postman
- Node.js
- MongoDB
- Mongoose
- Git y GitHub

## Instalación

1. Instalar las dependencias:

```bash
npm install
```

2. Iniciar MongoDB.

3. Ejecutar el servidor:

```bash
node index.js
```
